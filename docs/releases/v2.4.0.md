# AgentIsland 2.4.0

Uitgebracht op 9 september 2026.

## Hoogtepunten

- Claude Code kan toestemmingen, vragen en plancontroles rechtstreeks op het eiland tonen.
- Toestemming kan eenmalig, voor de huidige sessie of blijvend worden gegeven.
- Risicovolle opdrachten krijgen vóór goedkeuring een duidelijke waarschuwing.
- Communicatie verloopt via lokale, atomair geschreven verzoek- en antwoordbestanden.
- Bij een ontbrekend eiland of time-out valt Claude Code veilig terug op de eigen vraagweergave.
- Een lokaal sessievenster toont gesprekken, gereedschapsaanroepen en bestandsverschillen.
- De Nederlandse interface is toegevoegd en ontbrekende vertalingen vallen veilig terug op Engels.

## Installatie

De instellingenpagina kan de benodigde Claude-hooks installeren en verwijderen zonder bestaande gebruikershooks te overschrijven.
