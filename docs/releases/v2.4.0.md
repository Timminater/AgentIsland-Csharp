# AgentIsland for Windows - v2.4.0 Release Notes

发布日期：2026-09-09

## 版本概述

v2.4.0 让灵动岛从「只能看」变成「能回答」。通过接入 Claude Code 官方 hook（`PermissionRequest` 与 `PreToolUse`），agent 在请求权限、提问或提交计划时会阻塞等待，AgentIsland 直接把卡片推到灵动岛上，点一下即可 Allow / Deny、选择选项或批准计划——不需要切换到终端窗口，也**不使用任何模拟按键**。同时新增会话记录与差异查看器，并加入荷兰语界面。

## 核心更新

### 1. 内联审批与交互 (A1–A5)

- **A1 权限审批**：Claude Code 即将请求工具权限时触发 `PermissionRequest` hook。hook 把请求写入本地 spool 文件，岛弹出审批卡，用户点击后把 `decision.behavior`（allow / deny）写回，agent 原地继续。
- **A2 问答**：`PreToolUse` 仅拦截 `AskUserQuestion`，把选项渲染为按钮；点选后答案作为原因回传，模型据此继续，无需在终端重新选择。
- **A3 计划审批**：`PreToolUse` 拦截 `ExitPlanMode`，用内置轻量 Markdown 渲染器展示计划（标题、列表、代码块、粗体、行内代码），支持批准、拒绝或填写反馈。
- **A4 危险命令警示**：`CommandRisk` 用一张可测试的正则规则表，在按下 Allow 之前标出 `rm -rf /`、`git reset --hard`、`DROP TABLE`、`mkfs`、`dd of=/dev/*`、fork bomb、`git push --force`、`curl | sh` 等，并给出一句人话说明；只警告，绝不代替用户拒绝。
- **A5 授权范围**：Allow 支持「一次性 / 本会话 / 始终」。本会话授权落在 spool 的 `grants\` 目录（岛退出即清除，且由 hook 侧直接命中，不会再次打扰岛）；「始终」会向 Claude Code 自己的 `permissions.allow` 追加规则，首次修改前自动备份为 `.agentisland.bak`。

### 2. 传输与可靠性

- `FileInteractionChannel` 以「请求文件 + 响应文件」实现跨进程往返，全部先写临时文件再原子移动，读取方永远看不到半截 JSON。
- 岛每几秒写一次心跳；hook 先查心跳，没有运行中的岛就立即退出，**绝不让 agent 干等**。
- 请求超过 3 分钟由岛侧清理；hook 侧等待 120 秒后超时，一律回落到 Claude Code 原生提示——**任何情况下都不会代替用户放行**。

### 3. 安装入口

- 设置 → 服务新增「审批」区块，一键安装 / 移除两个 hook。hook 命令就是本 exe 的路径加一个模式参数（`--hook-claude-permission-request` / `--hook-claude-pre-tool-use`），单文件部署即可，无需额外脚本。
- 合并写入只触碰自己的条目，用户已有的 hook 原样保留；重复安装幂等，卸载后其他 hook 与权限规则不受影响。

### 4. 会话记录与差异查看器 (B4)

- 托盘菜单新增「Transcripts 和 diffs…」，打开独立窗口：左侧列出本机最近的会话（Claude / Codex），右侧按轮次渲染用户、助手与工具调用。
- 文件编辑从工具调用本身重建为差异视图：`Edit` 的 old/new 字符串、`Write` 的新文件、`MultiEdit` 的多段编辑，新增行绿色、删除行红色。
- 容错解析：正在写入的行、未知事件类型、非 JSON 行都不会中断渲染；纯本地只读。

### 5. 荷兰语界面 (E7)

- `L10n` 新增 `Dutch` 语言与 `nl-NL` 词表，缺失条目回落到英文而不是显示原始 key。
- 设置 → 通用 → 语言新增「Nederlands」；系统语言为荷兰语时自动启用；`AGENTISLAND_LANG=nl` 可强制指定。

### 6. 仓库指向

- 关于页、更新检查与设置页中的仓库链接由 `newton5555/AgentIsland-Csharp` 改为 `Timminater/AgentIsland-Csharp`；上游 `agent-island/agent-island` 的署名保留。

## 验证

- 新增 `InteractionTests`：危险命令分级、请求签名、spool 往返与超时、会话授权跨进程可见、协调器授权与过期清理、hook 安装合并 / 幂等 / 回滚、`Always allow` 去重、transcript 与 diff 重建、荷兰语接线。
- 顺带修复 `DeepSeekPeakHoursTests` 一处长期存在的时间相关断言：时间标签宽 30 DIP 且以标记为中心（`x - 15`），原断言误用标记半宽（`x - 0.75`），因此只在时段贴近首尾时才会通过。
