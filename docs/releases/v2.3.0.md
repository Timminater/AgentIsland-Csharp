# AgentIsland for Windows - v2.3.0 Release Notes

发布日期：2026-09-09

## 版本概述

v2.3.0 重构了灵动岛的**服务选择模型**：取消了沿用已久的“最多同时启用两家服务”限制，现在可任意勾选最多六家服务；顶部栏只渲染**一家活动服务**，鼠标悬停使顶栏展开时，中缝会出现所有已启用服务的图标，点击即可切换活动服务。Usage / Cost 页面同步改为“活动服务为主栏 + 其余服务紧凑行”的布局。

## 核心更新

### 1. 取消“最多两家”限制 (Unlimited Provider Selection)

- 移除 `ProviderSelection` 的 `MaxEnabled = 2` 上限与 `TryToggle` 的拒绝分支；`SanitizeEnabled` 不再截断。
- 设置页删除“先关一个再开”提示与 `SlotRefusalChanged` 拒绝路径，头部计数胶囊显示 `已选 / 总数`（最多 6）。
- `MaxEnabled` 保留为“全部已知服务数量”的具名常量，供设置页计数使用。

### 2. 顶部栏单一活动服务 (Single Active Provider)

- `IProviderVisibilityStore` 新增 `ActiveProvider` 与 `SetActiveProvider`；活动选择持久化到 `AgentIsland.activeProvider.v1`。
- 活动服务被禁用或未被本机检测到时，自动回落到首个可见服务；全部关闭时岛屿保持空态，绝不渲染幽灵服务。
- `IslandModel.SoloProvider` 改为返回活动服务；`IslandWindow` 始终走 solo 分栏（logo 居左、用量药丸居右），右flank 恒为空。
- `IslandViewModel` 的 `LeftProvider / RightProvider` 收敛为单一的 `ActiveProvider / ActiveActivity / ActiveThreadTitle`。

### 3. 悬停切换器 (Hover Switcher)

- 顶栏中缝新增 `ProviderSwitcher`：为每个已启用且已检测的服务渲染一枚图标，活动服务高亮。
- 仅在 Peek（悬停展开）状态显示——Compact 中缝过窄，Expanded 中缝由面板标题占用。
- 点击图标直接切换活动服务，事件标记 `Handled`，不会误触发展开面板的点击。
- 仅一家服务时切换器自动隐藏。

### 4. 浮动布局与页面布局适配

- `IslandModel.NotchWidth` 在浮动放置时按切换器所需宽度自适应（`max(64, 每服务 32px)`），避免图标被裁剪。
- Usage / Cost 页面新增底部紧凑行区域：活动服务保持主栏展示，其余已启用服务以“品牌标记 + 名称 + 关键指标”紧凑呈现。

### 5. 文案与注释一致性

- 更新 `DisplayProvider`、`ProviderVisibilityStore`、`IslandWindow` 注释与中英文案（`L10n`）以匹配单活动模型；移除已废弃的“最多两家”文案键。

## 验证

- 本地 `dotnet test tests/AgentIsland.Tests/AgentIsland.Tests.csproj`
- 结果：选择规则、单活动布局、设置页、ViewModel 与全部常规测试通过；仅 1 项与运行机器区域设置相关的既有失败除外（`ReportData.FormatDelta` 使用当前区域格式，荷兰语环境下 `20.0` 渲染为 `20,0`）。
