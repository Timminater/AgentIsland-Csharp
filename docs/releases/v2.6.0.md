# AgentIsland for Windows - v2.6.0 Release Notes

发布日期：2026-09-22

## 版本概述

v2.6.0 为顶栏加入可选的「预计用尽时间」。当当前 provider 的剩余额度低于用户设置的阈值，并且近期数据确实呈下降趋势时，百分比或余额旁会显示紧凑的 `≈42m` 倒计时。预测只使用本机已获取的官方额度/余额快照，不制造额外请求。

## 核心更新

### 1. 可配置阈值与平均窗口

- 设置 → 提醒新增独立开关，默认关闭。
- 百分比 provider 可设置 1–99% 的剩余额度显示阈值，默认 20%。
- 平均窗口支持动态、5、10、15、30 与 60 分钟。
- 实际计算窗口不会短于当前 provider 刷新间隔；例如每 30 分钟刷新时，选择 5 分钟仍会诚实地使用并标注 30 分钟数据分辨率。
- 动态模式在 provider 正在工作时采用最近 15 分钟趋势；本地会话暂停或空闲时立即隐藏旧预测。

### 2. 保守、可解释的预测

- 至少需要两个时间不同且剩余值下降的可靠样本，才会显示预测。
- 固定窗口在最新完整采样间隔没有下降时隐藏预测。
- 额度重置或余额充值会自动开启新趋势段，重置前后的数据不会错误拼接。
- 数据错误、过期、零下降或推算结果已经过期时不显示 countdown。
- 预测复用现有 5–30 分钟 provider 刷新，不提高 API 调用频率。

### 3. 顶栏展示

- 低于阈值时，原重置倒计时临时替换为琥珀色用尽预测，例如 `12% · ≈42m`。
- 悬停提示展示预计剩余时间和实际采用的平均窗口。
- DeepSeek 单币种余额在检测到可靠下降后显示到 0 的预测；预测显示时把高峰/低峰圆点移到 tooltip，为金额和倒计时保留空间。
- Countdown 每 30 秒更新，不需要等待下一次 provider 刷新。

## 验证

- 新增下降速率、动态暂停、固定窗口停滞与充值/重置测试。
- 顶栏百分比和余额 pill 的紧凑呈现均有 WPF 渲染断言。
- 完整测试基线：91 项（90 项常规测试 + 1 项压力/资源测试）。
- 原生 UI snapshot sweep 覆盖启用状态、设置页与顶栏倒计时。
