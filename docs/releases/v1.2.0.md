# AgentIsland 1.2.0

Uitgebracht op 6 september 2026.

## Hoogtepunten

- De toepassing gebruikt dependency injection, Generic Host en beheerde achtergrondtaken.
- Instellingen zijn getypeerd en worden atomair opgeslagen.
- Netwerkverzoeken gebruiken time-outs, herhalingen en snelle afhandeling wanneer het systeem offline is.
- Providers verklaren hun eigen mogelijkheden voor activiteit, gebruik, kosten en navigatie.
- Een reproduceerbare jaarlange stressproef controleert verwerking van grote sessiearchieven.
