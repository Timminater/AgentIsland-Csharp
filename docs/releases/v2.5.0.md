# AgentIsland for Windows - v2.5.0 Release Notes

发布日期：2026-09-13

## 版本概述

v2.5.0 聚焦可靠性、完整性与可用性：审批通道可安全处理并发写入，Claude 多问题交互完整回传，Hook 安装状态能够准确诊断；托盘、报告和会话记录现覆盖全部已启用服务。此版本同时补强键盘与辅助功能支持，并为自动更新加入 SHA-256 完整性校验。

## 核心更新

### 1. 审批与交互可靠性

- 请求、响应和心跳采用进程内按路径串行化的原子写入，消除并发替换临时文件时的访问冲突。
- 审批轮询阻止重入，后台计时器异常不会再终止应用；心跳写入降频而不影响请求响应速度。
- Claude `AskUserQuestion` 支持最多四个问题、单选、多选、选项和自由文本，并按官方 `PreToolUse` 响应结构回传。
- 会话授权签名包含 provider、tool、session 与工作目录，防止权限跨会话意外复用。
- Hook 安装检测区分 Missing、Partial、Installed 与 Invalid；设置页会显示准确状态和失败原因。

### 2. 托盘、报告与会话记录

- 托盘从全部已启用 provider 计算最紧急状态，并在提示中覆盖 Claude、Codex、Antigravity、Grok、Cursor 与 DeepSeek。
- 三个及以上 provider 的周报/月报使用真实全局占比堆叠图和完整图例；双 provider 对战布局保持不变。
- 会话源使用有界优先队列统一排序，避免某一来源先填满结果；工具响应按 `tool_use_id` 精确关联。
- 编辑记录改为真实行级差异，清楚标出新增、删除和上下文行；超大内容使用有界回退算法。

### 3. 界面与可访问性

- 设置页新增 Notes 标签，并修复从外部入口直接打开指定设置标签。
- What's New 恢复为每个版本显示一次，内容更新为当前 Windows 六服务体验，演示与快照模式不会打扰启动。
- Toggle、分段选择和胶囊按钮支持键盘操作与辅助功能名称；荷兰语界面补齐当前文案并修复语言选择裁切。
- 启动异常写入崩溃日志、显示可理解的错误并以失败码退出，不再静默失败。

### 4. 更新安全与发布质量

- Release 生成并发布与 zip 同名的 `.sha256` 文件。
- 自动安装前严格验证 SHA-256；无校验文件的旧发布仅提供手动下载。
- Release CI 运行原生 UI 快照巡检，覆盖审批、会话、DeepSeek 对话框与设置页。

## 验证

- Debug 与 Release 构建均为 0 warning / 0 error。
- 完整测试套件：86/86 通过（85 项常规测试 + 1 项压力/资源测试）。
- 原生荷兰语 UI 快照巡检通过，关键快照 12/12 生成。

## 发布产物

- 完整性校验：`AgentIsland-2.5.0-win-x64.zip.sha256`
- 适用系统：Windows 10 / Windows 11 x64
